# 🌟 КлавіоВсесвіт — інтерактивна клавіатурна пригода для 2 класу

Самостійна освітня HTML-гра українською мовою. Створена за темами «Пристрої для роботи з текстом» і «Пристрої для обчислень».

## ▶️ Запуск

Відкрийте `index.html` у браузері. Для гри не потрібні встановлення, облікові записи, сервер або інтернет. Адаптовано для комп’ютерів, інтерактивних панелей та мобільних екранів.

## 🌍 Опублікування на GitHub Pages

1. Створіть **публічний** репозиторій `klavio-vsesvit-2` на GitHub.
2. Завантажте файли `index.html`, `favicon.svg`, `.nojekyll` і цей `README.md` у корінь гілки `main` (не ZIP-архів).
3. Відкрийте **Settings → Pages** і в **Build and deployment** оберіть **Deploy from a branch**.
4. Встановіть **Branch: main**, **Folder: / (root)** і натисніть **Save**.
5. Майбутня адреса для акаунта `prostovchytel-debug`: https://prostovchytel-debug.github.io/klavio-vsesvit-2/

Опублікування може потребувати кількох хвилин після збереження налаштувань GitHub Pages.
